
## Tema 5 - Bucles

| Ejercicios | Descripción |
| --- | --- |
| [Cohete](Cohete.java) | Este programa cuenta desde 5 hasta 0 y luego muestra “¡Despegue! 🚀” |
| [Tabla del Nueve](TablaDelNueve.java) | Este programa muestra la tabla de multiplicar del 9 (del 1 al 10) usando un for. |
| [Nota](Nota.java) | Este programa convierta una nota numérica (double nota) en su calificación textual. |
| [Escalera Números](EscaleraNumeros.java) | Este programa imprime una escalera de números. |
| [Números Primos](NumerosPrimos.java) | Este programa imprime todos los números primos del 1 al 50, cada uno en su línea. |
| [Suma Hasta Cero](SumaHastaCero.java) | Este programa sume números enteros introducidos por el usuario hasta que escriba 0. |
