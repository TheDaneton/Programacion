## Tema 5 - Bucles

| Ejercicios | Descripción |
| --- | --- |
| [Cohete](Cohete.java) | Este programa cuenta desde 5 hasta 0 y luego muestra “¡Despegue! 🚀” |
| [Tabla del Nueve](TablaDelNueve.java) | Este programa muestra la tabla de multiplicar del 9 (del 1 al 10) usando un for. |
| [Nota](Nota.java) | Este programa convierta una nota numérica (double nota) en su calificación textual. |
| [Escalera Números Derecha](EscaleraNumerosDer.java) | Este programa imprime una escalera de números hacia la derecha. |
| [Escalera Números Izquierda](EscaleraNumerosIzq.java) | Este programa imprime una escalera de números hacia la izquierda. |
| [Escalera Números](EscaleraNumeros.java) | Este programa imprime una escalera de números. |
| [Números Primos](NumerosPrimos.java) | Este programa imprime todos los números primos del 1 al 50, cada uno en su línea. |
| [Suma Hasta Cero](SumaHastaCero.java) | Este programa sume números enteros introducidos por el usuario hasta que escriba 0. |
| [Números Pares](NumerosPares.java) | Este programa pide un número entero y muestra todos los números pares comprendidos entre 1 y ese número. |
| [Contar Cifras](ContarCifras.java) | Este programa pide un número entero positivo y calcula cuántas cifras tiene sin convertirlo a texto. |
| [Rectángulo Asteriscos](RectanguloAsteriscos.java) | Este programa pide el número de filas y columnas y dibuja un rectángulo de asteriscos. |
| [Cuadrado Numérico](CuadradoNumerico.java) | Este programa pide un número y muestra un cuadrado con números del 1 al N en cada fila. |
| [Matriz Números](MatrizNumeros.java) | Este programa pide un número y muestra una matriz en la que cada posición contenga el número de su fila multiplicado por el número de su columna.  |
