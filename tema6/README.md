## Tema 6 - Métodos

| Ejercicios | Descripción |
| --- | --- |

| [Ejercicio 4](VolumenCilincro.java) | Este programa calcula el volumen de un cilindro. |

| [Ejercicio 6](NumerosAmigos.java) | Este programa decide si dos números enteros positivos son amigos. |
| [Ejercicio 7](DiaSemanaFecha.java) | Este programa lee fechas validas por teclado y calcula el día de la semana que corresponde a esa fecha. |
